# context-lint Specification

| Document | Read when |
| --- | --- |

| [configuration-cli.md](configuration-cli.md) | Changing configuration discovery, schema, CLI flags, or exit codes. |
| [validation-parsing.md](validation-parsing.md) | Changing graph validation, path resolution, Markdown parsing, or reference extraction. |
| [diagnostics.md](diagnostics.md) | Changing diagnostic codes, output shapes, required target expansion, or excludes behavior. |
| [actions-distribution.md](actions-distribution.md) | Changing GitHub Actions usage, packaging, installation, or release distribution. |
| [implementation-testing.md](implementation-testing.md) | Changing package layout, dependency choices, tests, future scope, or non-functional requirements. |
